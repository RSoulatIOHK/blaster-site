how it works

Lean → Optimizer → SMT → Result

Blaster doesn't call Z3 directly. It first simplifies your goal through ~40 algebraic rewriting passes, then emits a minimal SMT-Lib 2 query.

Lean Goal
n + 0 = n
your theorem
Optimizer
n = n
add-identity removed
SMT-Lib 2
(assert (not (= n n))) (check-sat)
query sent to Z3
Z3
unsat
unsatisfiable → valid
Result
✓ Valid · 4ms
goal closed

What Blaster handles today

higher_order.lean
#blaster [ ∀ (x : Nat) (xs : List Nat), !xs.isEmpty → (xs.map (Nat.add x)).head! ≥ x]
✓ Valid · higher-order functions
polymorphism.lean
#blaster [ (∀ (α) (a b : α) [BEq α], a == b → a = b) → ∀ (x y : Either α β) [BEq α] [BEq β], x == y → x = y]
✓ Valid · polymorphism + typeclass
mutual_rec.lean
theorem A_self_size (a : A) : (A.self a).sizeA = a.sizeA + 1 := by blaster
✓ Valid · mutually inductive types
